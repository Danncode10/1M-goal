## 🌐 Platforms to Sign Up & Post

### 1. [Upwork](https://www.upwork.com) ⭐ Priority
- **Status:** Setting up profile
- **Best for:** Long-term clients, serious projects, AI/automation gigs
- **My angle:** Full-Stack Developer | Google Apps Script | AI Automation & n8n
- **Notes:** See `/UPSKILL/upwork-profile-guide.md` for full setup details

### 2. [Fiverr](https://www.fiverr.com)
- **Status:** To do
- **Best for:** Fixed-price gigs, clients come to you
- **My angle:** Landing pages (₱7,000), Management Systems, AI Chatbots
- **Notes:** Create gigs matching my existing service packages

### 3. [Freelancer.com](https://www.freelancer.com)
- **Status:** To do
- **Best for:** Bidding on projects, good volume of small web/PHP jobs
- **My angle:** Bid on web dev, automation, and AI agent projects

### 4. [Trabahero](https://www.trabahero.ph)
- **Status:** To do
- **Best for:** Philippine-based clients, local freelance market
- **My angle:** Full-stack + AI for local businesses

### 5. [OnlineJobs.ph](https://www.onlinejobs.ph)
- **Status:** To do
- **Best for:** Filipino freelancers, virtual/remote project-based work
- **My angle:** Web dev, automation, data science roles

### 6. [Jobstreet](https://www.jobstreet.com.ph) / [Kalibrr](https://www.kalibrr.com)
- **Status:** To do
- **Best for:** PH-based companies posting freelance/project contracts
- **My angle:** Contract web developer or project-based hire
