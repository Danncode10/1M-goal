## Content Pillars (What to Post)

### 1. Education (40%) — Build Trust
- "5 reasons your negosyo needs a website"
- "Bakit hindi kailangan ng malaking budget para magkaroon ng website"
- "How to get found on Google — tips for small businesses"
- "What is SEO and why should Filipino businesses care"

### 2. Portfolio / Work (30%) — Show Results
- Screenshots of websites built
- Before/after of client projects
- Behind-the-scenes of building a site
- "I built this website in X days"

### 3. Personal / Story (20%) — Build Connection
- Your OJT to freelancer journey
- "Studying web dev while on OJT in Baguio"
- Life as a web developer from Nueva Vizcaya
- Struggles and wins — Filipinos love relatable stories

### 4. Offers / CTA (10%) — Convert
- "Free website mockup for the first 3 clients"
- "Message me for a free consultation"
- Service announcements and promos

## Follower Growth Strategy

### Phase 1 — 0 to 200 Followers (Month 1-2)
- [ ] Join 5 Filipino business Facebook groups
- [ ] Post 1 helpful tip per group per week (no selling)
- [ ] Update personal FB bio: "Web Developer | Founder @DannDigital"
- [ ] Invite personal FB friends to like the page
- [ ] Post on personal profile about DannDigital launch

### Phase 2 — 200 to 1,000 Followers (Month 3-6)
- [ ] Start TikTok/Reels — short web dev content
- [ ] Create LinkedIn profile, connect with PH business owners
- [ ] Post on Reddit r/phclassifieds (free web services offer)
- [ ] Offer free mockup to generate word-of-mouth

### Phase 3 — 1,000+ Followers (Month 6+)
- [ ] Run first Facebook Boost (₱100-200/day)
- [ ] Lead gen ad: "Get a free website mockup"
- [ ] Retarget visitors from danndigital.com

## DO NOT
- Buy fake followers — kills organic reach, looks fake to clients
- Spam groups with ads — instant ban, ruins reputation
- Post then disappear — consistency is everything
- Run paid ads before having a website and portfolio
